# Muyang Chen — Photography

A standalone Astro photography portfolio, independent from the technical blog at
[`muyang-ic.github.io`](https://muyang-ic.github.io/).

Production URL: `https://muyang-ic.github.io/photography/`

A custom domain such as `photography.muyangchen.com` or `muyang.photo` can be
attached later without moving this repository.

```bash
npm install
npm run dev
```

The placeholder photographs are loaded from Unsplash and can be replaced in
`src/pages/index.astro` without changing the layout:

- “Courtyard” — Miguel Picq
- “Still Water” — Hannah Reding
- “After Midnight” — Benjamin Chambon
